ReferenceResidualConvergence

This Convergence is a DefaultNonlinearConvergence with a customized reference residual for its relative convergence checks. See ReferenceResidualProblem for more information.

With a variational inequality solver (-snes_type vinewtonrsls or vinewtonssls, used with Bounds), the residual at degrees of freedom held at a bound (the active set) is excluded from the residual norms, since the bound constraint holds there in place of the residual equation.

Per-variable absolute tolerances

A residual cannot drop below a round-off floor. Variables whose residuals differ by many orders of magnitude have floors that differ in the same way, so one nl_abs_tol can be below the floor of one variable and far above the floor of another. The "variable_nl_abs_tol" parameter replaces nl_abs_tol for the variables that it lists. Variables that it does not list use nl_abs_tol. All variables in a group of "group_variables" must have the same tolerance. The acceptable_multiplier applies to these tolerances also.

[Convergence<<<{"href": "../../syntax/Convergence/index.html"}>>>]
  [conv]
    type = ReferenceResidualConvergence<<<{"description": "Check the convergence of a problem with respect to a user-supplied reference solution. Replaces ReferenceResidualProblem, currently still used in conjunction with it.", "href": "ReferenceResidualConvergence.html"}>>>
    reference_vector<<<{"description": "The tag name of the reference residual vector."}>>> = 'ref'
    nl_rel_tol<<<{"description": "Nonlinear Relative Tolerance"}>>> = 0
    nl_abs_tol<<<{"description": "Nonlinear Absolute Tolerance"}>>> = 1e-12
    variable_nl_abs_tol<<<{"description": "Pairs of a variable name and the absolute tolerance that replaces nl_abs_tol in that variable's convergence check. Variables in a group must have the same tolerance."}>>> = 'u 1e-4'
  []
[]
(moose/test/tests/convergence/reference_residual_convergence/variable_abs_tol.i)

# Two decoupled variables whose residuals differ in magnitude by the factor coef. The round-off floor
# of each residual scales with its magnitude, so no single absolute tolerance is both above the floor
# of u and tight enough for v. The relative tolerance is zero, so only absolute tolerances decide
# convergence.

coef = 1e8

[Mesh]
  type = GeneratedMesh
  dim = 1
  nx = 10
[]

[Problem]
  extra_tag_vectors = 'ref'
[]

[Variables]
  [u]
  []
  [v]
  []
[]

[Kernels]
  [u_diff]
    type = CoefDiffusion
    variable = u
    coef = ${coef}
  []
  [u_rxn]
    type = PReaction
    variable = u
    coefficient = ${coef}
    power = 2
  []
  [u_f]
    type = BodyForce
    variable = u
    value = ${coef}
  []
  [v_diff]
    type = Diffusion
    variable = v
  []
  [v_rxn]
    type = PReaction
    variable = v
    coefficient = 1
    power = 2
  []
  [v_f]
    type = BodyForce
    variable = v
    value = 1
  []
[]

[BCs]
  [u]
    type = RobinBC
    boundary = 'left right'
    coefficient = ${coef}
    variable = u
    extra_vector_tags = 'ref'
  []
  [v]
    type = RobinBC
    boundary = 'left right'
    coefficient = 1
    variable = v
    extra_vector_tags = 'ref'
  []
[]

[Postprocessors]
  [u_avg]
    type = ElementAverageValue
    variable = u
  []
  [v_avg]
    type = ElementAverageValue
    variable = v
  []
[]

[Convergence]
  [conv]
    type = ReferenceResidualConvergence
    reference_vector = 'ref'
    nl_rel_tol = 0
    nl_abs_tol = 1e-12
    variable_nl_abs_tol = 'u 1e-4'
  []
[]

[Executioner]
  type = Steady
  solve_type = NEWTON
  petsc_options_iname = '-pc_type'
  petsc_options_value = 'lu'
  nl_max_its = 10
  nonlinear_convergence = conv
[]

[Outputs]
  csv = true
[]
