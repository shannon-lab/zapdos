ADArrayRobinBC

Imposes the integrated boundary condition on every component of an array variable, using automatic differentiation.

The boundary condition contributes

to the weak form of a diffusion operator, where is the test function and is the component-wise product. With it is a Neumann boundary condition like ArrayNeumannBC. The Jacobian is computed with automatic differentiation by the base class ADArrayIntegratedBC, which provides AD residuals for integrated boundary conditions on array variables.

Example Input Syntax

[BCs<<<{"href": "../../syntax/BCs/index.html"}>>>]
  [left]
    type = ADArrayDirichletBC<<<{"description": "Imposes the essential boundary condition $\\vec{u}=\\vec{g}$, where $\\vec{g}$ are constant, controllable values.", "href": "ADArrayDirichletBC.html"}>>>
    variable<<<{"description": "The name of the variable that this residual object operates on"}>>> = u
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = left
    values<<<{"description": "The values the components must take on the boundary"}>>> = '1 2'
  []
  [right]
    type = ADArrayRobinBC<<<{"description": "Imposes the integrated boundary condition $\\nabla u \\cdot \\vec{n} = h - \\alpha u$ on every component of an array variable, using automatic differentiation.", "href": "ADArrayRobinBC.html"}>>>
    variable<<<{"description": "The name of the variable that this residual object operates on"}>>> = u
    boundary<<<{"description": "The list of boundary IDs from the mesh where this object applies"}>>> = right
    value<<<{"description": "The prescribed flux $h$ of each component"}>>> = '0.5 -1'
    alpha<<<{"description": "The Robin coefficient $\\alpha$ of each component"}>>> = '2 0'
  []
[]

  • search_methodnearest_node_connected_sidesChoice of search algorithm. All options begin by finding the nearest node in the primary boundary to a query point in the secondary boundary. In the default nearest_node_connected_sides algorithm, primary boundary elements are searched iff that nearest node is one of their nodes. This is fast to determine via a pregenerated node-to-elem map and is robust on conforming meshes. In the optional all_proximate_sides algorithm, primary boundary elements are searched iff they touch that nearest node, even if they are not topologically connected to it. # Robin boundary condition grad(u).n = h - alpha u on a two-component array variable. The same
# problem written with two standard variables is solved in robin_reference.i; both write the
# component integrals to the same gold file.
[Mesh]
  type = GeneratedMesh
  dim = 2
  nx = 6
  ny = 6
[]

[Variables]
  [u]
    components = 2
  []
[]

[Kernels]
  [diff]
    type = ADArrayDiffusion
    variable = u
  []
[]

[BCs]
  [left]
    type = ADArrayDirichletBC
    variable = u
    boundary = left
    values = '1 2'
  []
  [right]
    type = ADArrayRobinBC
    variable = u
    boundary = right
    value = '0.5 -1'
    alpha = '2 0'
  []
[]

[Executioner]
  type = Steady
  solve_type = NEWTON
  # this input and robin_reference.i share a gold file, so both converge far below the CSVDiff
  # relative tolerance of 5.5e-6 for their results to agree regardless of the solver path
  nl_rel_tol = 1e-12
[]

[Postprocessors]
  [int0]
    type = ElementIntegralArrayVariablePostprocessor
    variable = u
    component = 0
  []
  [int1]
    type = ElementIntegralArrayVariablePostprocessor
    variable = u
    component = 1
  []
[]

[Outputs]
  file_base = robin_out
  csv = true
[]
