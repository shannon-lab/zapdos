ReporterTimes

Import times from one or more reporters, for example other Times

In order to retrieve a Reporter with the ReporterTimes, it must be a vector of floating point numbers (std::vector<Real>).

The times will be extracted from all the reporter vectors and sorted.

Example File Syntax

In this example, the ReporterTimes is combining the times from two other Times, using the fact that Times objects are Reporters in the back-end.

[Times<<<{"href": "../../syntax/Times/index.html"}>>>]
  [input]
    type = InputTimes<<<{"description": "Times set directly from a user parameter in the input file", "href": "InputTimes.html"}>>>
    times<<<{"description": "Times to store in the times vector"}>>> = '0.2 0.4 0.9'
    outputs<<<{"description": "Vector of output names where you would like to restrict the output of variables(s) associated with this object"}>>> = none
  []
  [input_2]
    type = InputTimes<<<{"description": "Times set directly from a user parameter in the input file", "href": "InputTimes.html"}>>>
    times<<<{"description": "Times to store in the times vector"}>>> = '0.2 0.5 0.6'
    outputs<<<{"description": "Vector of output names where you would like to restrict the output of variables(s) associated with this object"}>>> = none
  []
  [reporter]
    type = ReporterTimes<<<{"description": "Import times from one or more reporters, for example other Times", "href": "ReporterTimes.html"}>>>
    reporters<<<{"description": "Reporter(s) containing the times."}>>> = 'input/times input_2/times'
  []
[]
(moose/test/tests/times/reporter_times.i)

  • reportersReporter(s) containing the times.

    C++ Type:std::vector<ReporterName>

    Controllable:No

    Description:Reporter(s) containing the times.

    Controllable:No
