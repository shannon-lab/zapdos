CSGAction

Controls the generation of the Constructive Solid Geometry (CSG) representation of the mesh generators in the input file.

Overview

This Action holds the parameters of the [ConstructiveSolidGeometry] input block, which enables CSG-only mode from the input file and configures the CSG JSON output. Please refer to ConstructiveSolidGeometry for more details.

  • active__all__ If specified only the blocks named will be visited and made active

    Default:__all__

    C++ Type:std::vector<std::string>

    Controllable:No

    Description:If specified only the blocks named will be visited and made active

  • expand_unitsTrueWhether to expand all engineering units into basic CSG components before output.

    Default:True

    C++ Type:bool

    Controllable:No

    Description:Whether to expand all engineering units into basic CSG components before output.

  • generate_csgTrueWhether to generate and output the CSG representation of the mesh generators instead of the finite element mesh, then exit. Ignored when --mesh-only, --split-mesh, or --parse-neml2-only is passed on the command line.

    Default:True

    C++ Type:bool

    Controllable:No

    Description:Whether to generate and output the CSG representation of the mesh generators instead of the finite element mesh, then exit. Ignored when --mesh-only, --split-mesh, or --parse-neml2-only is passed on the command line.

  • inactiveIf specified blocks matching these identifiers will be skipped.

    C++ Type:std::vector<std::string>

    Controllable:No

    Description:If specified blocks matching these identifiers will be skipped.

  • output_fileName of the CSG JSON output file (Default: "_csg.json"). Overridden by --csg-only .

    C++ Type:std::string

    Controllable:No

    Description:Name of the CSG JSON output file (Default: "_csg.json"). Overridden by --csg-only .

Optional Parameters

  • control_tagsAdds user-defined labels for accessing object parameters via control logic.

    C++ Type:std::vector<std::string>

    Controllable:No

    Description:Adds user-defined labels for accessing object parameters via control logic.
