ElemSideNeighborLayersGeomTester

User object to calculate ghosted elements on a single processor or the union across all processors.

Overview

A user object to test whether or not geometric ghost elements are correctly reserved. element_side_neighbor_layers is used to specify the number of layers of geometric ghosting elements that will be preserved via a geometric relationship manager.

Input Parameters

  • element_side_neighbor_layersNumber of layers to ghost

    C++ Type:unsigned short

    Controllable:No

    Description:Number of layers to ghost

    C++ Type:unsigned int

    Controllable:No
