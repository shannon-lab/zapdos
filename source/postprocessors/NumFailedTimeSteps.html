NumFailedTimeSteps

Collects the number of failed time steps from the time stepper.

Description

NumFailedTimeSteps reports the number of failed time steps. With current_time_step_only = true it reports only the failed solves of the current time step, which is reset to zero when a time step converges. Executed on TIMESTEP_BEGIN, this is the number of failures before the current attempt, which Controls can use to handle a repeated time step differently from the first attempt.

Example Input Syntax

[Postprocessors<<<{"href": "../../syntax/Postprocessors/index.html"}>>>]
  [num_failed]
    type = NumFailedTimeSteps<<<{"description": "Collects the number of failed time steps from the time stepper.", "href": "NumFailedTimeSteps.html"}>>>
  []
[]
