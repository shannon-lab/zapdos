TimeWindowedStatisticsPostProcessor

Windowed statistics (mean, std, drift) and a running time average of a postprocessor, using only samples from start_time onwards.

Description

The TimeWindowedStatisticsPostProcessor reports a time statistic of another postprocessor, selected with "postprocessor". For example, it can be used to monitor whether a quantity in a pseudo-transient or statistically steady simulation has settled, or to report its time average once it has. Only samples from time steps with "start_time" are used, so an initial transient can be excluded.

One sample is recorded per time step. With the number of samples in the window, which is the smaller of "window" and the number of samples recorded so far, the "statistic" parameter selects one of the following:

  • mean: the arithmetic mean of the last samples,

  • std: the sample standard deviation of the last samples,

    which is 0 when only one sample has been recorded.

  • time_integrated_mean: the time-weighted mean of all samples since averaging started,

    where is the part of the time step of sample after "start_time", so that no time before "start_time" is included. At "start_time", the integration interval is empty and the current value of the monitored postprocessor is returned.

  • statistics_time: the total time over which time_integrated_mean is taken.

The window is measured in time steps, not in simulation time, and the windowed statistics weigh all samples equally regardless of the time step size. Before "start_time" is reached, mean and time_integrated_mean return the current value of the monitored postprocessor, while std and statistics_time return 0.

commentnote

At most one sample is recorded per time step, so the statistics are not affected if the object executes several times in a time step. Samples are taken from the value of the monitored postprocessor at the time of execution, so the default execute_on = TIMESTEP_END is the intended use.

Example Input Syntax

In this example, the monitored postprocessor f is equal to the simulation time, which advances by 1 each time step. Averaging starts at and the window holds the last 3 time steps. One TimeWindowedStatisticsPostProcessor is declared for each statistic: at , the windowed mean is the mean of 4, 5 and 6, the std is 1, and the time_integrated_mean is the mean of 3 through 6 weighted by the parts of the time steps after , which are 0.5 for the sample at and 1 for the others.

[Postprocessors<<<{"href": "../../syntax/Postprocessors/index.html"}>>>]
  [f]
    type = FunctionValuePostprocessor<<<{"description": "Computes the value of a supplied function at a single point (scalable)", "href": "FunctionValuePostprocessor.html"}>>>
    function<<<{"description": "The function which supplies the postprocessor value."}>>> = f
  []
  [mean]
    type = TimeWindowedStatisticsPostProcessor<<<{"description": "Windowed statistics (mean, std, drift) and a running time average of a postprocessor, using only samples from start_time onwards.", "href": "TimeWindowedStatisticsPostProcessor.html"}>>>
    postprocessor<<<{"description": "The postprocessor to monitor."}>>> = f
    start_time<<<{"description": "Simulation time from which samples are used for all statistics."}>>> = 2.5
    window<<<{"description": "Number of time steps in one window."}>>> = 3
    statistic<<<{"description": "Which statistic to report."}>>> = mean
  []
  [std]
    type = TimeWindowedStatisticsPostProcessor<<<{"description": "Windowed statistics (mean, std, drift) and a running time average of a postprocessor, using only samples from start_time onwards.", "href": "TimeWindowedStatisticsPostProcessor.html"}>>>

    start_time<<<{"description": "Simulation time from which samples are used for all statistics."}>>> = 2.5
    window<<<{"description": "Number of time steps in one window."}>>> = 3
    statistic<<<{"description": "Which statistic to report."}>>> = std
  []
  [time_integrated_mean]
    type = TimeWindowedStatisticsPostProcessor<<<{"description": "Windowed statistics (mean, std, drift) and a running time average of a postprocessor, using only samples from start_time onwards.", "href": "TimeWindowedStatisticsPostProcessor.html"}>>>
    postprocessor<<<{"description": "The postprocessor to monitor."}>>> = f
    start_time<<<{"description": "Simulation time from which samples are used for all statistics."}>>> = 2.5
    window<<<{"description": "Number of time steps in one window."}>>> = 3
    statistic<<<{"description": "Which statistic to report."}>>> = time_integrated_mean
  []
  [statistics_time]
    type = TimeWindowedStatisticsPostProcessor<<<{"description": "Windowed statistics (mean, std, drift) and a running time average of a postprocessor, using only samples from start_time onwards.", "href": "TimeWindowedStatisticsPostProcessor.html"}>>>

# The monitored postprocessor is f = t, sampled at t = 1, 2, ..., 6 with dt = 1.
# Statistics only use samples with t >= start_time = 2.5, so with window = 3:
#   mean                 : 1, 2, 3, 3.5, 4, 5
#   std                  : 0, 0, 0, sqrt(0.5), 1, 1
# start_time falls inside a time step, so the time integral excludes [2, 2.5] and the sample at
# t = 3 only has weight 0.5:
#   time_integrated_mean : 1, 2, 3, (0.5 * 3 + 4) / 1.5, (0.5 * 3 + 4 + 5) / 2.5,
#                          (0.5 * 3 + 4 + 5 + 6) / 3.5 = 1, 2, 3, 11/3, 4.2, 33/7
#   statistics_time      : 0, 0, 0.5, 1.5, 2.5, 3.5
[Mesh]
  type = GeneratedMesh
  dim = 1
[]

[Problem]
  solve = false
[]

[Functions]
  [f]
    type = ParsedFunction
    expression = 't'
  []
[]

[Postprocessors]
  [f]
    type = FunctionValuePostprocessor
    function = f
  []
  [mean]
    type = TimeWindowedStatisticsPostProcessor
    postprocessor = f
    start_time = 2.5
    window = 3
    statistic = mean
  []
  [std]
    type = TimeWindowedStatisticsPostProcessor
    postprocessor = f
    start_time = 2.5
    window = 3
    statistic = std
  []
  [time_integrated_mean]

    postprocessor = f
    start_time = 2.5
    window = 3
    statistic = time_integrated_mean
  []
  [statistics_time]

    postprocessor = f
    start_time = 2.5
    window = 3
    statistic = statistics_time
  []
[]

  num_steps = 6
  dt = 1
[]
