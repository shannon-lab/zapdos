MeshInfo

A Reporter object for tracking mesh information, such as the number of elements, nodes, or degrees-of-freedom. The "items" parameter controls the items computed. MeshInfo will declare reporters for each item requested.

Example Input Syntax

The following input file snippet demonstrates the use of the MeshInfo object.

[Reporters<<<{"href": "../../syntax/Reporters/index.html"}>>>]
  [mesh_info]
    type = MeshInfo<<<{"description": "Report mesh information, such as the number of elements, nodes, and degrees of freedom.", "href": "MeshInfo.html"}>>>
  []
[]
(moose/test/tests/reporters/mesh_info/mesh_info.i)

Input Parameters

  • elem_itemsItems to include when outputting element information

    C++ Type:MultiMooseEnum

    Options:all, bounding_box, dim, elem_mapping_type, elem_type, hmax, hmin, neighbor_ids, node_ids, num_sides, points, processor_id, unique_id, volume

    Controllable:No

    Description:Items to include when outputting element information

  • elem_qualitiesElement quality metrics to include when outputting element information

    C++ Type:MultiMooseEnum

    Options:all, jacobian, max_angle, min_angle

    Controllable:No

    Description:Element quality metrics to include when outputting element information

  • itemsThe iteration information to output; if not provided, everything will be output.

    C++ Type:MultiMooseEnum

    Options:elems, num_dofs, num_dofs_nonlinear, num_dofs_auxiliary, num_dofs_constrained, num_elements, num_nodes, num_local_dofs, num_local_dofs_nonlinear, num_local_dofs_auxiliary, num_local_elements, num_local_nodes, local_elems, local_sidesets, local_subdomains, sidesets, subdomains

    Controllable:No

    Description:The iteration information to output; if not provided, everything will be output.

    Description:Bounded (min or max) element quality metrics to include when outputting sideset information

  • sideset_itemsItems to include when outputting sideset information

    C++ Type:MultiMooseEnum

    Controllable:No

  • subdomain_elem_qualitiesBounded (min or max) element quality metrics to include when outputting subdomain information

    Controllable:No

    Description:Bounded (min or max) element quality metrics to include when outputting subdomain information

  • subdomain_itemsItems to include when outputting subdomain information

    C++ Type:MultiMooseEnum
