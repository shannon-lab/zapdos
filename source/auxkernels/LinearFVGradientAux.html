LinearFVGradientAux

Copies the cell-centered gradient of a linear finite-volume variable, computed with a selected gradient method, into a vector auxiliary variable.

Overview

This AuxKernel copies the cell-centered gradient of a MooseVariableLinearFVReal into a constant monomial vector auxiliary variable. By default it reads the gradient computed with the method set by the gradient_method parameter of the variable. Setting "gradient_method" instead reads the result of any other built-in method or object in [FVGradientMethods], and registers that method for the variable if no other object has. Gradients from methods other than the default of the variable cannot be accessed through the functor system, so this object is the way to output or postprocess them, for example with ElementVectorL2Error.

Example Input File Syntax

In this example, the gradient of u is copied using both its default Green-Gauss method and a limited Green-Gauss method:

[AuxKernels<<<{"href": "../../syntax/AuxKernels/index.html"}>>>]
  [grad_u_default]
    type = LinearFVGradientAux<<<{"description": "Copies the cell-centered gradient of a linear finite-volume variable, computed with a selected gradient method, into a vector auxiliary variable.", "href": "LinearFVGradientAux.html"}>>>
    variable<<<{"description": "The name of the variable that this object applies to"}>>> = grad_u_default
    linear_fv_variable<<<{"description": "Linear finite-volume variable whose gradient is copied."}>>> = u
  []
  [grad_u_limited]
    type = LinearFVGradientAux<<<{"description": "Copies the cell-centered gradient of a linear finite-volume variable, computed with a selected gradient method, into a vector auxiliary variable.", "href": "LinearFVGradientAux.html"}>>>
    variable<<<{"description": "The name of the variable that this object applies to"}>>> = grad_u_limited
    linear_fv_variable<<<{"description": "Linear finite-volume variable whose gradient is copied."}>>> = u
    gradient_method<<<{"description": "Gradient method whose result is copied. Defaults to the gradient method of the variable."}>>> = limited
  []
[]

[FVGradientMethods<<<{"href": "../../syntax/FVGradientMethods/index.html"}>>>]
  [limited]
    type = FVGreenGaussGradient<<<{"description": "Green-Gauss cell-centered gradient method.", "href": "../fvgradientmethods/FVGreenGaussGradient.html"}>>>
    limiter<<<{"description": "Limiter to apply to gradients produced by this method."}>>> = venkatakrishnan
  []
[]
(moose/test/tests/variables/linearfv/gradient-aux.i)

  • search_methodnearest_node_connected_sidesChoice of search algorithm. All options begin by finding the nearest node in the primary boundary to a query point in the secondary boundary. In the default nearest_node_connected_sides algorithm, primary boundary elements are searched iff that nearest node is one of their nodes. This is fast to determine via a pregenerated node-to-elem map and is robust on conforming meshes. In the optional all_proximate_sides algorithm, primary boundary elements are searched iff they touch that nearest node, even if they are not topologically connected to it. This is more CPU-intensive but is necessary for robustness on any boundary surfaces which has disconnections (such as Flex IGA meshes) or non-conformity (such as hanging nodes in adaptively h-refined meshes).

    solver_sys = 'u_sys'

  []
[]

    family = MONOMIAL_VEC
    order = CONSTANT
  []
  [grad_u_limited]
    family = MONOMIAL_VEC
    order = CONSTANT
  []
[]

[FVGradientMethods]
  [limited]
    type = FVGreenGaussGradient
    limiter = venkatakrishnan
  []
[]

[LinearFVKernels]
  [diffusion]
    type = LinearFVDiffusion
    variable = u
    diffusion_coeff = 1
    use_nonorthogonal_correction = false
  []
  [source]
    type = LinearFVSource
    variable = u
    source_density = source_func
  []
[]

[LinearFVBCs]
  [dir]
    type = LinearFVAdvectionDiffusionFunctorDirichletBC
    variable = u
    boundary = 'left right top bottom'
    functor = analytic_solution
  []
[]

[AuxKernels]
  [grad_u_default]
    type = LinearFVGradientAux
    variable = grad_u_default
    linear_fv_variable = u
  []
  [grad_u_limited]
    type = LinearFVGradientAux
    variable = grad_u_limited
    linear_fv_variable = u
    gradient_method = limited
  []
[]

[Functions]
  [source_func]
    type = ParsedFunction
    expression = '2*(1.5-y*y)+2*(1.5-x*x)'
  []
  [analytic_solution]
    type = ParsedFunction
    expression = '(1.5-x*x)*(1.5-y*y)'
  []
  [analytic_gradient]
    type = ParsedVectorFunction
    expression_x = '-2*x*(1.5-y*y)'
    expression_y = '-2*y*(1.5-x*x)'
  []
[]

[Postprocessors]
  [default_gradient_error]
    type = ElementVectorL2Error
    variable = grad_u_default
    function = analytic_gradient
    execute_on = FINAL
  []
  [limited_gradient_error]
    type = ElementVectorL2Error
    variable = grad_u_limited

  []
