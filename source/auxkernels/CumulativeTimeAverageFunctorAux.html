CumulativeTimeAverageFunctorAux

Running time-weighted mean of a functor, starting at a given simulation time.

Description

The CumulativeTimeAverageFunctorAux computes the running time-weighted mean of a functor, which may be a finite element or finite volume variable, a function, or a functor material property, selected with "functor". It can be used, for example, to compute the mean field of a turbulent or otherwise unsteady simulation.

Averaging starts at the first time step with "start_time". With the later of "start_time" and the beginning of that first time step, the average is updated at each time step as

where is the value of the functor at the current time and is the part of the time step after , so that no time before is included. This is equivalent to the time-weighted mean of all values since averaging started. Up to and including , the variable holds the current value of the functor.

By default, the functor is integrated over each time step with the rectangle rule using its current value , the same quadrature as the implicit Euler time integrator. This is first order accurate in , but for statistically stationary signals averaged over many time steps the quadrature error is generally considered much smaller than the sampling error of the average. For more accuracy, setting "time_integration_scheme" to trapezoidal-rule replaces with the trapezoidal rule over the time step, , which is second order accurate. This only improves the accuracy if the functor is itself computed with a second order (or higher) time integrator, for example CrankNicolson or BDF2. On the first averaged time step, the value at is linearly interpolated between and . The trapezoidal rule requires the functor to support evaluation at the previous time step.

The update only depends on the average from the previous time step, so executing the auxiliary kernel several times in a time step gives the same result.

commentnote

The functor is evaluated once per element, so the auxiliary "variable" must be elemental and should be of CONSTANT MONOMIAL type. Nodal variables are rejected.

Example Input Syntax

In this example, the function u equals and the simulation time advances by 1 each time step. The CumulativeTimeAverageFunctorAux stores the time average of u in the CONSTANT MONOMIAL variable u_avg, starting at . In each element, the average is the element centroid coordinate times the time-weighted mean of the times sampled since averaging started.

    functor<<<{"description": "The variable or functor to time-average. A functor is any of the following: a variable, a functor material property, a function, a postprocessor or a number."}>>> = u

# The averaged functor is u = t * x, evaluated at the element centroids x = 0.5 and 1.5
# at t = 1, 2, ..., 6 with dt = 1. Averaging is over [start_time, t] with start_time = 2.5,
# which falls inside a time step, so the sample at t = 3 only has weight 0.5. Before that the
# variable holds u. The rectangle rule average is x times
#   1, 2, 3, (0.5 * 3 + 4) / 1.5, (0.5 * 3 + 4 + 5) / 2.5, (0.5 * 3 + 4 + 5 + 6) / 3.5
#   = 1, 2, 3, 11/3, 4.2, 33/7
# The trapezoidal rule is exact for u linear in t, so the trapezoidal average is x times the
# exact mean of t over [2.5, t], (2.5 + t) / 2:
#   1, 2, 2.75, 3.25, 3.75, 4.25
[Mesh]
  type = GeneratedMesh
  dim = 1
  nx = 2
  xmax = 2
[]

[Problem]
  solve = false
[]

[Functions]
  [u]
    type = ParsedFunction
    expression = 't * x'
  []
[]

[AuxVariables]
  [u_avg]
    family = MONOMIAL
    order = CONSTANT
  []
[]

[AuxKernels]
  [u_avg]
    type = CumulativeTimeAverageFunctorAux
    variable = u_avg
    functor = u
    start_time = 2.5
  []
[]

[Postprocessors]
  [u_avg_left]
    type = PointValue
    variable = u_avg
    point = '0.5 0 0'
  []
  [u_avg_right]
    type = PointValue
    variable = u_avg
    point = '1.5 0 0'
  []
[]

[Executioner]
  type = Transient
  num_steps = 6
  dt = 1
[]

[Outputs]
  csv = true
